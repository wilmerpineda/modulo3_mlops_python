# Resultados de aprendizaje

Formulaciones pedagógicas propuestas; la correspondencia literal con el syllabus institucional está pendiente.

Al finalizar, el estudiante podrá:

1. Distinguir cambios en las entradas, salidas, relación predictiva y rendimiento observado, explicando qué evidencia permite diagnosticar cada uno.
2. Instrumentar un servicio y construir reportes de calidad, desempeño y drift con Evidently, Prometheus y Grafana.
3. Implementar pruebas y workflows que produzcan candidatos reproducibles y detecten regresiones antes de una actualización.
4. Justificar la aceptación o rechazo de un modelo y demostrar una recuperación de versión con trazabilidad.
5. Analizar diferencias de desempeño entre grupos y proponer mitigaciones reconociendo incertidumbre y límites del dataset.
6. Relacionar escalabilidad, resiliencia y costos con objetivos operativos medibles.

| Resultado | Evidencia |
|---|---|
| Diagnosticar | Informe de escenarios estable, drift y degradación |
| Instrumentar | API, `/metrics`, dashboard y reglas de alerta |
| Automatizar | CI y retraining manual/programado |
| Actualizar | Comparación, decisión, registro de promoción y rollback |
| Gobernar | Model card, análisis por edad y responsables |
| Operar | Prueba de carga, incidente y estimación de costos |

## Prerrequisitos

Python, pandas y clasificación binaria; particiones de entrenamiento y evaluación; Git y pull requests; FastAPI, Docker y serialización de modelos. Si falta alguno, retome las secciones equivalentes de los módulos 1 y 2 antes de comenzar la actividad.
